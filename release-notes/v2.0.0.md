# WorldShot Log v2.0.0 Release Notes

WorldShot Log v2.0.0 is a major update that adds in-app image editing for VRChat screenshots.

Edited images are saved under a new name without overwriting originals, making it easier to prepare screenshots for posts, thumbnails, Booth listings, galleries, emoji, and stickers.

## Changes

- Added an image editor that opens from the photo detail view.
- Added adjustments for brightness, exposure, contrast, highlights, shadows, whites, blacks, temperature, tint, saturation, vibrance, clarity, texture, fade, grain, and vignette.
- Added smart auto correction, learned correction, and adjustment strength controls.
- Added RGB / HSV tone curves with histogram display.
- Added crop ratios, rotation, flip, zoom, position controls, rulers, and a rule-of-thirds grid.
- Added full-image blur, radial blur, privacy masks, mosaic, fill masks, and text overlays.
- Added undo / redo, full reset, compare view, and save-as controls.

## Notes

- Original images are not overwritten.
- Edited images are saved under separate names.
- Windows build artifacts are generated under `out/make/squirrel.windows/x64/`.
