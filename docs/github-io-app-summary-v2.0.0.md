# WorldShot Log Website Feature Summary v2.0.0

WorldShot Log is a Windows Electron app for organizing, reviewing, and lightly editing VRChat screenshots.

It helps users browse screenshots by date or world, check where photos were taken, add memos and labels, prepare posts, and perform simple image edits without leaving the app.

## Key Capabilities

- Browse VRChat screenshots by year, month, day, or world.
- Open a detail view with file name, destination folder, date taken, resolution, and world information.
- Manage world metadata, World IDs, world names, memos, labels, and favorites.
- Edit screenshots in-app without overwriting originals.
- Adjust light, color, tone curves, crop, rotation, blur, privacy masks, and text overlays.
- Back up, restore, export, and run data health checks.

## Short Site Copy

WorldShot Log is a Windows app for organizing, reviewing, and preparing VRChat screenshots. It combines date and world-based photo management with lightweight editing tools such as brightness adjustments, tone curves, cropping, privacy masks, and text overlays. Original screenshots are never overwritten.
